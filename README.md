# Aishwarya K G — Personal Portfolio

A personal portfolio showcasing my journey as an Artificial Intelligence and Machine Learning undergraduate, developer, and technology enthusiast.

Welcome to my portfolio! This website is designed with a retro pixel-art aesthetic to present my technical skills, projects, research interests, and development journey through an interactive experience.

## Live Website

[Visit My Portfolio](https://aishwaryakg2415.github.io)

## Features

- **Pixel-Art Interface:** Retro gaming-inspired design with custom pixel-art elements.
- **Interactive Introduction:** Game-inspired welcome screen.
- **About Me:** Background, interests, and academic journey.
- **Skills:** Technical skills across programming, web development, and AI/ML.
- **Projects:** Showcase of academic, personal, and development projects.
- **Research:** Highlights of research interests and academic work.
- **Interactive Chatbot:** A chatbot that provides information about my profile, skills, and projects.
- **Theme Switching:** Day and night visual modes.
- **Sound Effects:** Optional retro-style audio interactions.
- **Responsive Design:** Supports different screen sizes.

## Getting Started

No additional dependencies or build tools are required.

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/aishwaryakg2415/aishwaryakg2415.github.io.git
```

2. Navigate to the project directory:

```bash
cd aishwaryakg2415.github.io
```

3. Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code.

## Deployment

This portfolio is hosted using GitHub Pages.

To deploy:

1. Push the project files to a public GitHub repository.
2. Navigate to repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the `main` branch and `/ (root)` folder.
6. Save the configuration.

The website will be available at:

`https://aishwaryakg2415.github.io`
